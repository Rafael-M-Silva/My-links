# My-links

Aplicação de links pessoais com servidores HTTP nativos de Node.js para a página e a API.

Projeto desenvolvido para fins educacionais.

**Tecnologias:** `HTML`, `CSS`, `JavaScript`, `Node.js`.

## Executar localmente

```bash
npm install
npm run start
```

A API fica em `api/index.js` e pode ser iniciada em outro terminal com `npm run api`.
